Instructions

How to Use This Content Manager:

  • View Courses: See all courses currently in the system below
  • Edit Course: Click the edit button to modify course details
  • Add Course: Use the "Add New Course" button to create a new course
  • Delete Course: Remove courses that are no longer offered

Data Storage:

All course data is stored in /content/courses.json. Make sure to back up this file regularly.

Note:

This is a demo content manager. In a production environment, you would connect this to a backend API and database for persistent storage.
